# Mixed-format host assessment

This small, fictional tender checks actual file retrieval, prescribed fields,
independent limits, a longer narrative, a rendered page cap and reviewer feedback.
It contains no employer or client information. Keep assessment outputs in a new
private folder outside the installed skill. Do not replace these fixtures with
real company material in the public repository.

## Files supplied

- [tender.docx](tender.docx): exact questions, scoring, field limits and page rules.
- [response-template.docx](response-template.docx): prescribed response layout.
- [capability.docx](company/capability.docx): fictional marketing starting point.
- [transition-standard.docx](company/transition-standard.docx): controlled approach
  with a reference to another document that must be followed.
- [annex-a-controls.pdf](company/annex-a-controls.pdf): referenced controls.
- [evidence-register.xlsx](company/evidence-register.xlsx): evidence on several
  named sheets; read headers, scope, dates and limitations with the values.
- [reviewer-feedback.txt](reviewer-feedback.txt): supplied feedback for a second
  step, after saving the original answer. It is not source evidence.

## Run in QwenWork at work

Install the current skill, then paste this with the actual installed path:

```text
Use tender-response. Complete the fictional assessment in
[installed skill]/evals/mixed-format/.
Read tender.docx and use response-template.docx. Start company research with
company/capability.docx, then actively search and read the permitted company
folder, including referenced records and relevant workbook sheets.
Save the completed response, separate answer-only Q1-Q4 text files, and one
private evidence/search review to a new folder outside the installed skill.
Check each field under its own stated limit and render/inspect the final response
against the page cap. Give the actual searches, source locators, measured counts
and unresolved requirements. Report unavailable tools honestly. Do not read the
reviewer-feedback file until I request a revision. Use no real company files.
```

Then ask:

```text
Apply reviewer-feedback.txt to the saved Q2 answer using tender-response.
Inspect the relevant company evidence again. Preserve the original answer,
save a revised Q2 and updated response document, recount and recheck the page
limit, and record a compact reusable lesson in the private response library.
Do not invent an assessor score or change the public skill.
```

## Assess the result

Check the tool operations as well as fluent prose. The agent must actually read
binary documents, follow the annex reference, preserve spreadsheet context,
resolve outdated claims, distinguish an approved approach from allocated staff,
and keep private notes outside the client document. It must not claim a passed
mandatory requirement when the evidence supports a negative answer.

Check Q1, Q2, Q3 and Q4 independently using the conventions in the tender. Q3 uses
UTF-16 code units; Q4 includes its subheadings. Inspect the rendered pages at
normal size for readable text, clipping, leftover placeholders and the page cap.
The final response remains a working draft if mandatory compliance is unresolved.

Record host/model/version if exposed, skill release, queries, read source
locators, output files, counts, renderer and observed limits. A Codex trial or
XML extraction does not establish that your QwenWork installation can access
these files. Unavailable connector, reader or renderer capability is a reported
limitation, not an evidence absence or an automatic pass.
