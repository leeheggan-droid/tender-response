do not store completed packs in the public skill repository.

## Draft answer — client-facing text only

Use the required numbering and structure. Keep this separate from review notes
so the exact submission field can be counted independently.

## Internal review — excluded from submission

- Status: working draft / ready for owner review / verified for submission format.
- Coverage: each requirement mapped; missing or weak elements named.
- Claim checks: evidence IDs and relevant comparability limitations.
- Search receipt: sources, queries, inspected documents and real limitations.
- Measurement: exact text checked, method, actual count(s), cap(s), remaining space;
  page render/check if required; portal verification if still outstanding.
- Gaps/conflicts: specific impact, attempted searches and evidence/owner needed.
- Proposed commitments: assumptions, dependencies and tender-specific approvals.
- Consistency: roles, dates, figures and terminology checked across responses.

This record supports review. It does not replace a tender's own submission checks.
